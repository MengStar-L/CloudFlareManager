CF-R2Manager v1 Design

Linux-first, single-administrator Cloudflare control plane implemented as one Go binary with embedded React assets.

Runtime

The process exposes separate loopback listeners for admin, S3, WebDAV, and Workers AI. SQLite WAL stores configuration, indexes, jobs, and audit data. systemd credentials provide the AES-256-GCM master key.

R2

One external logical bucket is backed by program-owned R2 buckets across authorized accounts. A durable object index records placement. The allocator applies explicit rules, then scores storage, Class A, Class B, and health headroom. S3 and WebDAV share the same index.

D1

D1 supports database lifecycle operations, schema and data browsing, a conservative SQL console, import/export, Time Travel, analytics, and backups into the unified R2 pool.

Workers AI

The AI listener provides Cloudflare's OpenAI-compatible endpoints plus native model execution. Routing uses observed token and estimated Neuron usage, health, and rate limits. Prompt and response bodies are not retained by default.

Reliability

Persistent jobs, explicit object states, startup recovery, index rebuild, encrypted backups, protocol-native errors, bounded-memory transfers, and layered automated tests are release requirements.
