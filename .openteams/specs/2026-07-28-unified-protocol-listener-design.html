单端口统一协议入口

CF-R2Manager design note, 2026-07-28

将管理面板、S3、WebDAV 和 OpenAI 兼容接口统一到一个 HTTP 监听地址，同时保留各协议原始路径、鉴权和错误格式。

公共地址

服务地址识别依据
管理面板http(s)://host:14325/不匹配其他协议的请求
S3http(s)://host:14325AWS SigV4 Authorization 或预签名参数
WebDAVhttp(s)://host:14325/Basic Authorization 或 DAV 专用方法
AIhttp(s)://host:14325/v1受支持的 /v1/* 路径

路由优先级

  1. AWS SigV4 和 S3 预签名请求进入 S3，路径与 Host 不做改写。
  2. Basic Authorization 请求进入 WebDAV，使 WebDAV 文件可以使用任意路径。
  3. DAV 专用方法及 OPTIONS 进入 WebDAV，未认证发现请求仍获得 Basic challenge。
  4. 受支持的 /v1/* 路径进入 AI，缺少 Token 时返回 OpenAI 格式 401。
  5. 其余请求进入管理 API 和嵌入式前端。

配置迁移

新的规范字段为 listeners.http，默认 0.0.0.0:14325。旧配置没有该字段时继承 listeners.admin；若两者同时存在则使用 http。旧 s3、webdav 和 ai 地址不再启动监听器，并在启动日志中提示弃用。Metrics 保持独立且只允许回环地址。

模型目录

GET /v1/models 不再直通未知的上游兼容路径。AI 凭据通过验证后，服务使用现有 Cloudflare Models API 分页拉取目录，按 ID 去重、排序，并输出标准 OpenAI list/model 对象。无可用 AI 账号返回 503，上游目录失败返回 502，二者都使用 OpenAI 错误结构。

管理界面

新增受保护的 endpoints API，返回当前请求 origin 下的面板、S3、WebDAV 和 AI 地址以及逻辑桶名。访问密钥页面在每类凭据旁显示对应连接地址和复制操作，避免用户再次查找端口或遗漏 AI 的 /v1。

兼容与安全

  • S3 继续使用 path-style 和原有 SigV4 校验；反向代理必须保留 Host。
  • WebDAV 根目录、RaiDrive 发现、锁和 MOVE/COPY Destination 不变。
  • 升级后旧三个协议端口立即关闭，这是已确认的客户端配置变更。
  • 无认证普通 GET 根路径属于面板；WebDAV 通过 DAV 方法或 Basic Auth 识别。
  • 公网部署推荐由单一 HTTPS 站点反向代理统一入口。
