CF-R2Manager 浅色云端工作台

将当前控制台重构为浅色、优雅、具有明显但可控动效的运营工具。重构只触及 React 展示层，保留全部 Go API、权限模型和业务流程。

用户已确认 方案 A 明显丰富动效 桌面与移动端

设计结论

采用雾白工作区、浅色导航、石墨文字和多色功能语义。翡翠绿承担主要操作，Cloudflare 橙承担品牌点缀，钴蓝表达信息，珊瑚红表达风险。界面保持数据密度，不使用营销式布局、装饰性渐变、光球或过度圆角。

目标与边界

需要达到

统一导航、表格、表单、下拉框、弹窗、加载和反馈状态；提供明显丰富的页面与组件动效；改善移动端导航和长表格体验。

明确不做

不修改 API、数据库和鉴权逻辑；不增加营销首页；不添加深色主题切换；不改变危险操作的业务语义。

视觉系统

品牌橙 #E85D2A

字体

本地打包 Manrope Variable，仅用于英文、数字、品牌和重点数值；中文使用系统 UI 字体。字体文件随二进制发布，不访问外部 CDN，并附 OFL 许可说明。

形状与层次

固定格式控件使用稳定尺寸；圆角限制在 6-8px。页面分区采用留白和分隔线，卡片只用于指标、重复项目、弹窗和确实需要边界的工具区域。

布局与导航

桌面

使用 232-248px 浅色侧栏和宽工作区。当前导航项使用移动底板与彩色图标。页面标题、状态与主要操作形成稳定顶层，内容不嵌套装饰卡片。

移动端

使用紧凑顶部工具栏和侧滑导航抽屉，替换当前拥挤的横向图标栏。表单单列排列，表格保留横向查看，关键命令始终可触达。

组件策略

组件设计行为要求
按钮图标优先，文本只用于明确命令；主操作翡翠绿，品牌动作可用橙色。固定高度、清晰焦点、提交时禁用重复操作。
Select / ComboBox统一触发器、浮层、选中标记和下拉箭头。弹性展开、完整键盘导航；选项多于 8 项时提供搜索。
表格轻表头、稳定行高、悬浮强调、状态使用圆点与文字。长值截断并可查看完整值；移动端允许横向滚动。
标签页分段控制用于模式切换，滑动底板指示当前项。切换不改变容器尺寸，保留焦点和键盘操作。
Dialog / Drawer危险确认使用对话框，移动导航使用抽屉。焦点锁定、Escape 关闭、关闭后恢复触发点焦点。
Toast / Banner右上角临时反馈，页面内错误使用可关闭横幅。错误不清空已有数据；成功信息自动消退。
Skeleton / Empty骨架屏匹配最终布局；空状态简洁，不放功能说明文字。异步加载不引起页面大幅跳动。

实现边界

使用 motion 处理页面、布局和共享元素动画；使用 react-aria-components 提供 Select、ComboBox、Dialog、Menu 的可访问交互。CSS 负责颜色、悬浮、焦点和 reduced-motion 降级。

  • web/src/styles/tokens.css：颜色、间距、阴影、尺寸、动效令牌。
  • web/src/styles/base.css：重置、字体、页面基础和焦点行为。
  • web/src/styles/components.css：按钮、表单、表格、状态、弹窗、骨架屏。
  • web/src/styles/pages.css：R2、D1、AI 等领域页面布局。
  • web/src/styles/responsive.css：桌面、平板、移动断点。
  • web/src/components/SelectField.tsx：Select 与可搜索 ComboBox 的统一入口。
  • web/src/components/Motion.tsx：页面切换、列表入场和 reduced-motion 封装。
  • web/src/components/ConfirmDialog.tsx、ToastProvider.tsx、Skeleton.tsx：统一反馈组件。
  • 更新现有 AppShell.tsx、UI.tsx、Login.tsx 与各页面，只替换展示和控件调用。

数据流与错误处理

数据流

页面继续通过现有 api 客户端读取数据。动效组件只接收渲染状态，不持有领域数据；控件通过受控值和现有事件回调连接业务逻辑。

异常状态

加载显示结构匹配的骨架；读取失败保留现有数据；写入失败恢复按钮并显示错误；危险命令在服务器要求的确认之外增加清晰的 UI 确认。

验收标准

  • 覆盖概览、账号、R2、D1、Workers AI、访问密钥、任务与审计、登录页。
  • 在 1440×900、1024×768、390×844 三种视口验证布局和文字不重叠。
  • 验证 Select/ComboBox 键盘操作、抽屉和对话框焦点管理、Escape 关闭与焦点恢复。
  • 验证所有页面无非预期横向溢出、浏览器控制台零错误、资源加载成功。
  • 验证标准动效与 prefers-reduced-motion 两种模式。
  • 运行 npm run lint、npm run build 和 go test -count=1 ./...。
  • 重新构建嵌入式前端并重启本地测试服务，交付可直接查看的页面和关键截图。

风险控制

包体

按页面继续代码分割；只引入需要的 Motion 与 React Aria 模块，构建后检查主包和懒加载包体。

行为回归

UI 组件不直接调用 API；逐页保留现有提交和刷新路径，浏览器验收覆盖关键工作流。

性能

不动画大面积阴影、滤镜或表格布局；只动画 transform 与 opacity，长列表不做无限交错。

离线发布

字体和前端资源全部本地嵌入；新增许可证写入 NOTICE，不依赖运行时外部资源。
