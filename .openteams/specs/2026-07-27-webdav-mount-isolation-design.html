WebDAV 挂载点隔离与文件管理根目录

文件管理根目录以 WebDAV 凭据作为独立挂载点。每个挂载点拥有隔离的文件命名空间；旧版全局文件一次性归入 gamesync。

目标与边界

最终根目录：直接显示 gamesync 和 test 两个文件夹，不显示“挂载点”和“根目录文件”统计区。

隔离要求：使用 gamesync 登录 WebDAV 时不能读取或修改 test 的文件，反之亦然。

  • 挂载点来源仅为 WebDAV 类型凭据；S3 和 AI 凭据不显示。
  • 空挂载点仍返回可访问的空根目录，保持 Windows/RaiDrive 等客户端正常连接。
  • 挂载点名称由凭据名称提供，但存储路径使用凭据 ID，重命名或轮换密钥不会移动文件。
  • 本次不增加跨挂载点移动、批量操作、回收站或 ZIP 下载。

方案选择

方案优点缺点结论
凭据 ID 内部命名空间稳定、无需跟随改名迁移、天然隔离管理接口需要虚拟根目录和路径转换采用
凭据名称作为对象前缀结构直观重名与改名需要递归迁移不采用
新增独立挂载点表生命周期最灵活引入不必要的数据模型和迁移复杂度暂不采用

命名空间与协议边界

内部保留前缀为 .cf-r2-manager/webdav/<credential-id>/。该前缀仅存在于逻辑对象索引中，用户界面、WebDAV URL 和审计资源名均不暴露它。

身份认证解析 WebDAV 凭据并取得稳定 ID。
路径映射把客户端路径 /save/a.dat 映射到该凭据的内部前缀。
R2 服务继续通过逻辑键定位原有物理对象，不改变物理键。
响应还原目录和属性响应只返回客户端可见的相对路径。
  • WebDAV 的 GET、PUT、DELETE、MKCOL、COPY、MOVE、PROPFIND、LOCK 和 UNLOCK 全部执行相同的命名空间映射。
  • 目录递归操作和后台任务接收已经映射的内部键，不能把目标移到其他挂载点。
  • S3 列表过滤保留前缀，直接读取、写入或删除保留前缀返回拒绝访问。
  • 外部可见对象键仍限制为 1024 字节；内部前缀长度不计入用户配额。

一次性旧数据迁移

迁移在监听器和后台任务启动前同步执行，只修改 SQLite 中的逻辑键，不复制或重新上传 Cloudflare R2 物理对象。

  1. 检查 system_settings 中的迁移完成标记。
  2. 选择最早创建的 WebDAV 凭据作为旧数据所有者；当前安装中该凭据为 gamesync。
  3. 在单个数据库事务中，为旧版全局逻辑键加上 gamesync 的内部前缀。
  4. 同步重写未完成的分片上传、WebDAV 锁和待恢复文件任务中的路径。
  5. 写入目标凭据 ID 和完成标记；任何步骤失败均回滚，服务不以半迁移状态启动。

若没有 WebDAV 凭据但存在旧文件，迁移保持待处理状态；创建第一个 WebDAV 凭据后执行。若保留前缀发生历史键冲突，迁移失败并给出明确日志，不覆盖现有数据。

管理接口

接口根目录行为挂载点内行为
GET /api/v1/files未传 mount_id 时返回 WebDAV 凭据虚拟文件夹传 mount_id 与相对 path，列出该挂载点一级子项
GET /api/v1/files/content不适用必须传 mount_id 与相对 key
PUT /api/v1/files/content拒绝上传到指定挂载点，保留现有覆盖语义
POST /api/v1/files/directories拒绝在指定挂载点创建目录
POST /api/v1/files/operations拒绝操作虚拟挂载点移动、重命名和删除均限制在同一 mount_id
  • 根目录挂载点条目包含 mount_id、显示名称、禁用状态和凭据更新时间；排序为名称升序。
  • 服务端以凭据 ID 查找 WebDAV 凭据，不接受客户端提交任意内部前缀。
  • 不存在、类型不符或已经删除的凭据返回 404；挂载点间路径越界返回 400。

凭据生命周期

  • 创建 WebDAV 凭据后，文件管理根目录立即出现对应空文件夹，不需要目录标记对象。
  • 轮换密钥或修改显示名称不改变内部命名空间。
  • 撤销凭据只禁止 WebDAV 登录；管理员仍可在文件管理页面查看和处理其文件。
  • 永久删除凭据记录前统计该命名空间。非空时返回 409 mount_not_empty；清空后才能删除。
  • 不会因撤销或删除凭据而自动递归删除文件。

页面行为

  • 文件管理根目录直接使用现有详细信息列表显示挂载点文件夹，删除顶部统计带。
  • 根目录仅显示刷新操作；“新建文件夹”和“上传文件”在进入挂载点后显示。
  • 面包屑为“根目录 > gamesync > 子目录”，哈希路由保存 mount_id 和相对路径。
  • 挂载点行只能打开和查看状态，不显示重命名、移动、下载或删除菜单。
  • 进入 gamesync 后显示迁移前的全部旧文件；进入 test 时初始为空。
  • 桌面端和移动端沿用同一列表结构，文字、按钮和面包屑不得重叠。

验证标准

  • 两个 WebDAV 凭据上传同名文件后，各自读取到自己的内容，目录列表互不可见。
  • 空的 test 挂载点通过 WebDAV PROPFIND 返回成功，且管理页面显示空文件夹。
  • 升级后原有 GameSync/ 和 claude.png 仅出现在 gamesync 内。
  • 迁移重复运行不改变数据；中途失败完整回滚；超长路径和保留前缀冲突被拒绝。
  • 撤销凭据后 WebDAV 登录失败但管理员仍能浏览；非空挂载点阻止永久删除凭据。
  • S3 无法列出或直接访问 WebDAV 内部前缀。
  • 运行 go test ./...、npm run build，并在桌面与 390px 移动视口验证根目录和挂载点内页面。
