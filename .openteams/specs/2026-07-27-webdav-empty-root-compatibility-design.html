WebDAV Empty Root Compatibility

CF-R2Manager design note, 2026-07-27

Allow RaiDrive to validate and mount the existing empty root collection by returning a valid root display name, without synthetic children or persisted R2 objects.

Observed Behavior

The WebDAV handler derives displayname with path.Base. For the root href /, trimming the trailing slash first produces an empty string and path.Base("") returns .. RaiDrive discards that root resource during its initial Depth: 0 validation and reports ValidateUrl: Not found file.

A local probe reproduced the production XML with RaiDrive 2025.12.30. Changing only the root displayname from . to / made the same client complete its four-request handshake and mount. A subsequent probe returned no child response at Depth: 1 and still mounted, proving that the virtual /.empty/ collection introduced in v0.1.5 is unnecessary.

Selected Design

The WebDAV handler will special-case only the root resource display name. Root properties use /; all non-root resources continue deriving their display name from the href. The v0.1.5 virtual /.empty/ behavior will be removed.

Data Flow

The existing property generation remains the source of truth. makeProperty assigns / when its normalized href is the root and otherwise keeps the existing basename calculation. Root listing logic returns only resources reported by the object service.

Compatibility

The root href, collection type, HTTP status, authentication, storage lookup, and child enumeration remain unchanged. A real object or implicit directory named .empty continues to behave normally because the synthetic collision path is removed. Non-root display names are unaffected.

Error Handling

Authentication, authorization, locking, and HTTP-to-R2 error mapping do not change. A failed index listing remains an upstream failure and must not be converted into an empty namespace.

Verification

  • Root Depth 0 has status 207, one collection response, href /, and display name /.
  • An empty root Depth 1 response contains only the root collection and no synthetic child.
  • A direct PROPFIND /.empty/ returns 404 unless real content creates that path.
  • Adding a real object returns the root and real child without changing the root display name.
  • The complete Go test suite passes.
  • After release deployment, RaiDrive 2025.12.30 completes the production handshake and mounts the empty namespace.

Scope

The product change is limited to the WebDAV handler and its tests. It does not create database rows, R2 objects, virtual resources, configuration fields, or UI controls.
