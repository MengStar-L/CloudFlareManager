WebDAV Empty Root Compatibility

CF-R2Manager design note, 2026-07-27

Allow RaiDrive to validate and mount an empty CF-R2Manager WebDAV namespace without creating an object in R2.

Observed Behavior

A root PROPFIND / currently returns the root collection and no child responses when the object index is empty. RaiDrive reports ValidateUrl: Not found file for that response, while the same endpoint mounts after at least one object exists.

Selected Design

The WebDAV handler will expose a virtual /.empty/ collection only while the entire committed object namespace is empty. The collection is generated in WebDAV responses and is never written to the object index or an R2 bucket.

RequestEmpty namespaceNamespace with real objects
PROPFIND /, Depth 0Return the root collection only.Unchanged.
PROPFIND /, Depth 1 or omittedReturn the root and virtual /.empty/ collections.Return only real children.
PROPFIND /.empty/Return the virtual collection.Use normal object and implicit-directory lookup; return 404 if it does not exist.

Data Flow

The existing root listing remains the source of truth. After a successful list, the handler adds the virtual response only when zero committed objects were returned. A direct lookup of /.empty/ performs a bounded root listing to confirm that the whole namespace is still empty before returning the synthetic collection.

Compatibility and Collisions

The placeholder disappears as soon as any committed object exists. If a user uploads content under .empty/, normal implicit-directory behavior takes over, so the path continues to work as a real directory. Other methods keep their existing behavior; the virtual collection is a discovery aid, not a persisted or independently deletable object.

Error Handling

Authentication, authorization, locking, and HTTP-to-R2 error mapping do not change. A failed index listing remains an upstream failure and must not be converted into an empty namespace.

Verification

  • An empty root Depth 1 response has status 207 and contains both collection responses.
  • A direct PROPFIND /.empty/ succeeds only while the namespace is empty.
  • Root Depth 0 does not include the virtual child.
  • Adding a real object removes the synthetic response without changing normal listings.
  • The complete Go test suite passes.

Scope

The change is limited to the WebDAV handler and its tests. It does not create database rows, R2 objects, configuration fields, or UI controls.
